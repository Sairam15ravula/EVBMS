# Plan 04-01: Explicit Physics-Based Extended Kalman Filter (EKF) & Safe Model Loader System

**Phase**: 4 (Advanced AI/ML Inference & Physics Engine)  
**Plan**: 04-01  
**Goal**: Build an Extended Kalman Filter (EKF) SoC estimation physics engine supporting NMC and LFP chemistries with explicit mathematical formulations, and a safe model loader with metadata validation and deterministic fallbacks.

## Requirements Addressed
- **ML-01**: Scalable ML model loader and versioning system serving XGBoost, Random Forest, and Isolation Forest models.
- **ML-02**: Hybrid physics + ML State of Charge (SoC) estimation module incorporating Extended Kalman Filtering (EKF) and Coulomb counting.

## Explicit Technical Constraints
1. EKF state vector \(x_k = [z_k, v_{rc,k}]^T\), 1RC Equivalent Circuit Model, sampling interval \(\Delta t = 1.0\text{s}\), discharge \(I > 0\), charge \(I < 0\).
2. Explicit chemistry requirement (`NMC` or `LFP`) with 1D interpolated OCV-SoC lookup tables. Does NOT default silently.
3. Validate SoC accuracy using MAE, RMSE (< 2.0%), and Max Error.
4. Model loader checks SHA256 checksums, loads metadata JSON, and exposes `model_ready` status. Deterministic physical fallbacks are tested.
5. Reuses Phase 1-3 REST endpoints, JWT auth, and repository layers.

## Files Modified & Created

### New Files
- `backend/services/soc_ekf.py` — Discrete EKF SoC estimator supporting NMC and LFP chemistries
- `backend/services/model_loader.py` — Centralized model loader, SHA256 checksum validator, sidecar metadata parser, and fallback executor

### Modified Files
- `backend/routes/predict.py` — Expose `POST /predict/soc-ekf` endpoint requiring explicit chemistry metadata

## Tasks

### Task 1: Build Centralized Model Loader & SHA256 Checksum Validator
- Create `backend/services/model_loader.py` providing `load_model_with_metadata()`, SHA256 verification, metadata JSON reading (`<model>_metadata.json`), and deterministic fallback triggers when models are unready.

### Task 2: Build Explicit EKF SoC Estimator
- Create `backend/services/soc_ekf.py` implementing state vector \(x_k = [z_k, v_{rc,k}]^T\), discrete Jacobian matrices \(F_k, H_k\), OCV lookup for NMC and LFP, and innovation updates.

### Task 3: Expose EKF Endpoint & Register Model Readiness
- Update `backend/routes/predict.py` to add `POST /predict/soc-ekf` endpoint accepting `chemistry` and telemetry parameters.

## Verification Criteria
1. EKF SoC estimator achieves MAE < 1.5%, RMSE < 2.0% on test drive cycles for both NMC and LFP chemistries.
2. `model_loader.py` verifies SHA256 checksums and falls back deterministically if model binary is missing or corrupted.
