# Plan 04-01: Physics-Based Extended Kalman Filter (EKF) SoC Estimator & Model Loader System

**Phase**: 4 (Advanced AI/ML Inference & Physics Engine)  
**Plan**: 04-01  
**Goal**: Build a hybrid Extended Kalman Filter (EKF) + Coulomb counting physics module and a centralized model loader & versioning manager in FastAPI.

## Requirements Addressed
- **ML-01**: Scalable ML model loader and versioning system serving XGBoost, Random Forest, and Isolation Forest models.
- **ML-02**: Hybrid physics + ML State of Charge (SoC) estimation module incorporating Extended Kalman Filtering (EKF) and Coulomb counting.

## Files Modified & Created

### New Files
- `backend/services/soc_ekf.py` — Extended Kalman Filter (EKF) SoC estimation algorithm with OCV lookup curves
- `backend/services/model_loader.py` — Centralized model loader, model metadata provider, and version manager

### Modified Files
- `backend/routes/predict.py` — Expose `POST /predict/soc-ekf` endpoint and update model status endpoint

## Tasks

### Task 1: Create Centralized Model Loader System
- Create `backend/services/model_loader.py` managing `.joblib` model loading, versioning tags (`v1.0.0`), and fallback resilience.

### Task 2: Implement Extended Kalman Filter (EKF) SoC Estimator
- Create `backend/services/soc_ekf.py` implementing 1RC Equivalent Circuit Model (ECM), OCV-SoC lookup tables for NMC/LFP chemistries, and Extended Kalman Filter state update equations.

### Task 3: Expose EKF SoC Endpoint in FastAPI
- Add `POST /predict/soc-ekf` route in `backend/routes/predict.py`.

## Verification Criteria
1. EKF SoC algorithm produces smooth SoC estimates with error < 2% across dynamic charge/discharge profiles.
2. Model loader safely initializes trained models or falls back to documented physical equations when binaries are missing.
