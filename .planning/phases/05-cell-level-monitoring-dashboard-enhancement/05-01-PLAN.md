# Plan 05-01: Configurable Chemistry-Aware Cell Monitoring Grid & Thermal Heatmap

**Phase**: 5 (Cell-Level Monitoring & Dashboard Enhancement)  
**Plan**: 05-01  
**Goal**: Create `CellGridMonitor.tsx` supporting configurable cell counts (e.g. 96, 108, 192), module layouts, chemistry-aware thresholds (NMC vs LFP), thermal heatmap toggle, and cell detail modal.

## Requirements Addressed
- **UI-01**: Interactive cell-level battery monitoring grid displaying individual cell voltages, temperature gradients, and delta variances.

## Explicit Technical Constraints
1. Dynamic cell count and module layout based on `vehicle.battery_pack.cell_count` metadata. Cell counts are NOT hardcoded.
2. Chemistry-aware thresholds (`NMC` vs `LFP`).
3. Backend safety state (`healthMetrics.anomalies`) is authoritative; UI visualizes state without inventing safety classifications.

### New Files
- `src/components/CellGridMonitor.tsx` — Configurable cell grid monitor supporting dynamic cell counts, chemistry thresholds, thermal heatmaps, and detail modal

### Modified Files

- `src/data/batteryData.ts` — Add configurable cell array generator function `generateCellVoltages(nominalV, cellCount, chemistry, imbalance)`
