# Plan 01-01: PostgreSQL / TimescaleDB Database Connection & Migration Pipeline Setup

**Phase**: 1 (Database Persistence & Data Architecture)  
**Plan**: 01-01  
**Goal**: Set up PostgreSQL / TimescaleDB database connection infrastructure, Docker environment configuration, Alembic migration scripts, and async database session management.

## Requirements Addressed
- **DATA-01**: PostgreSQL database schema configured with Alembic migrations for user accounts, vehicle assets, battery packs, and diagnostic alert logs.
- **DATA-02**: Time-series telemetry storage (TimescaleDB hypertable) for continuous voltage, current, temperature, and SoC/SoH samples.

## Files Modified & Created

### New Files
- `docker-compose.yml` — Containerized PostgreSQL 16 + TimescaleDB setup
- `backend/db/__init__.py` — Database module package initialization
- `backend/db/session.py` — Async SQLAlchemy engine & session factory configuration
- `backend/db/base.py` — SQLAlchemy `DeclarativeBase` base model definition
- `alembic.ini` — Alembic configuration file
- `alembic/env.py` — Async Alembic environment runner script
- `alembic/script.py.mako` — Migration template

### Modified Files
- `requirements.txt` / `backend/requirements.txt` — Add `sqlalchemy>=2.0.0`, `asyncpg`, `alembic`, `psycopg2-binary`

## Tasks

### Task 1: Add Database Dependencies & Docker Setup
- Add `sqlalchemy`, `asyncpg`, `alembic`, and `psycopg2-binary` to Python dependencies.
- Create `docker-compose.yml` exposing PostgreSQL 16 with TimescaleDB extension on port 5432.

### Task 2: Create Async Database Session Infrastructure
- Create `backend/db/base.py` defining `class Base(DeclarativeBase)`.
- Create `backend/db/session.py` initializing `create_async_engine` using `DATABASE_URL` (defaulting to `postgresql+asyncpg://postgres:postgres@localhost:5432/ev_bms`) and providing an async session dependency generator `get_async_session()`.

### Task 3: Initialize Alembic Async Migration Suite
- Generate Alembic setup (`alembic.ini` and `alembic/` directory).
- Configure `alembic/env.py` to import `Base.metadata` and execute async migrations using `async_engine_from_config`.

## Verification Criteria
1. `docker-compose up -d` or PostgreSQL connection connects successfully.
2. `alembic current` and `alembic heads` run without syntax or import errors.
3. Async session generator `get_async_session` instantiates cleanly.
