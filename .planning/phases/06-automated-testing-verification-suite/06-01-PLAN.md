# Plan 06-01: Comprehensive Pytest Backend, ML Validation & Failure Matrix Test Suite

**Phase**: 6 (Automated Testing & Verification Suite)  
**Plan**: 06-01  
**Goal**: Build automated Pytest backend suite covering 1RC EKF SoC accuracy, ML model quality metrics, SHA256 model loader failure matrix, data leakage checks, RBAC auth matrix, and database operations.

## Requirements Addressed
- **TEST-01**: Automated backend test suite with Pytest covering ML services, API endpoints, schema validation, and database operations.

## Explicit Testing Constraints
1. EKF SoC target: MAE <= 2.0% (target <= 1.5%), RMSE <= 2.0%.
2. Model loader failure cases: correct/incorrect checksum, corrupted model, missing model, missing/invalid metadata, and physical fallbacks.
3. Verify zero telemetry leakage across cell-grouped train/test splits.
4. Offline Gemini fallback tests (pass without `GEMINI_API_KEY`).
5. Auth & RBAC matrix tests (unauthenticated 401, expired JWT, role checks).
