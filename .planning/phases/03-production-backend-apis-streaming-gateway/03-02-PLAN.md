# Plan 03-02: FastAPI Production Fleet CRUD, Pack Diagnostics & Alert History APIs

**Phase**: 3 (Production Backend APIs & Streaming Gateway)  
**Plan**: 03-02  
**Goal**: Build FastAPI production REST APIs for vehicle fleet CRUD, battery pack metadata, diagnostic alert history pagination, and historical telemetry queries.

## Requirements Addressed
- **BACK-01**: Production-grade FastAPI prediction API endpoints with OpenAPI/Swagger documentation, input validation, and standard HTTP error contracts.
- **BACK-03**: Vehicle fleet management CRUD API endpoints (`/api/vehicles`, `/api/packs`, `/api/alerts`).
- **BACK-04**: Health check, metrics, and rate limiting middleware across Express and FastAPI services.

## Files Modified & Created

### New Files
- `backend/routes/vehicles.py` — Vehicle fleet management REST router (`GET /api/vehicles`, `POST /api/vehicles`, `GET /api/vehicles/{id}`, `DELETE /api/vehicles/{id}`)
- `backend/routes/alerts.py` — Alert logs & fault code router (`GET /api/alerts`, `PATCH /api/alerts/{id}/acknowledge`)
- `backend/routes/telemetry.py` — Historical telemetry query router (`GET /api/telemetry/history/{vehicle_id}`)
- `backend/schemas/fleet.py` — Pydantic validation models for vehicles, battery packs, and alert logs

### Modified Files
- `backend/app.py` — Mount `vehicles_router`, `alerts_router`, and `telemetry_router`

## Tasks

### Task 1: Create Fleet Pydantic Schemas
- Create `backend/schemas/fleet.py` defining schemas for vehicle creation, pack metadata, telemetry query filters, and alert responses.

### Task 2: Build Fleet & Pack Management Endpoints
- Create `backend/routes/vehicles.py` providing full CRUD operations connected to `VehicleRepository`.

### Task 3: Build Alert Logs & Telemetry History Endpoints
- Create `backend/routes/alerts.py` providing paginated alert logs and acknowledgment updates using `TelemetryRepository`.
- Create `backend/routes/telemetry.py` retrieving time-series telemetry history.
- Mount routers in `backend/app.py`.

## Verification Criteria
1. `GET /api/vehicles` lists vehicle assets cleanly from database.
2. `GET /api/alerts` returns paginated diagnostic alert logs.
3. FastAPI `/docs` generates complete interactive Swagger documentation for all routes.
