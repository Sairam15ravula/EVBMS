# Plan 02-02: RBAC Asset Access Control & Frontend Authentication State Manager

**Phase**: 2 (Authentication & User Management)  
**Plan**: 02-02  
**Goal**: Build vehicle asset scoping in backend repositories, React authentication state context, login/register UI view, and protected route wrapper components.

## Requirements Addressed
- **AUTH-03**: Vehicle asset assignment and organization-level data scoping.
- **AUTH-04**: Session persistence and route protection middleware in React frontend and Express/FastAPI backends.

## Files Modified & Created

### New Files
- `src/context/AuthContext.tsx` — React authentication state provider and `useAuth()` hook
- `src/components/ProtectedRoute.tsx` — Protected route guard wrapper component
- `src/components/LoginModal.tsx` — Interactive login & registration modal UI

### Modified Files
- `backend/routes/predict.py` — Add optional auth dependency to ML prediction endpoints
- `src/App.tsx` — Wrap app with `AuthProvider` and attach `LoginModal` & header auth status pill
- `src/types.ts` — Add `User`, `AuthState`, and role types

## Tasks

### Task 1: Scoped Asset Access Logic
- Enhance `backend/db/repositories/vehicle_repo.py` to enforce vehicle ownership scoping based on user role.
- Update `backend/routes/predict.py` to accept optional user authentication context.

### Task 2: React AuthContext & State Management
- Define `User`, `UserRole`, and `AuthState` types in `src/types.ts`.
- Create `src/context/AuthContext.tsx` providing `user`, `role`, `accessToken`, `login()`, `register()`, `logout()`, and silent refresh capabilities.

### Task 3: Login Modal & Protected Route Component
- Create `src/components/LoginModal.tsx` allowing users to log in or register directly from the dashboard.
- Create `src/components/ProtectedRoute.tsx` guarding authenticated views.
- Integrate `AuthProvider` and `LoginModal` into `src/App.tsx` and header.

## Verification Criteria
1. Unauthenticated users see an interactive Login button in the header.
2. Logging in updates React `AuthContext` state and persists session token.
3. Drivers can only view telemetry for vehicles assigned to their account.
