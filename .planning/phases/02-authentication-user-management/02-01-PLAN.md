# Plan 02-01: FastAPI Authentication Endpoints, Password Hashing & JWT Middleware

**Phase**: 2 (Authentication & User Management)  
**Plan**: 02-01  
**Goal**: Build user registration, login, token refresh, password hashing, and JWT security middleware in the Python FastAPI backend service.

## Requirements Addressed
- **AUTH-01**: User registration, login, password hashing (Argon2 / bcrypt), and JWT access/refresh token issue endpoints.
- **AUTH-02**: Role-based Access Control (RBAC) supporting Admin, Fleet Manager, Technician, and Driver roles.

## Files Modified & Created

### New Files
- `backend/services/auth.py` — Password hashing, JWT token creation, and payload verification utilities
- `backend/routes/auth.py` — Auth API routes (`POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/refresh`, `GET /api/auth/me`)
- `backend/schemas/auth.py` — Pydantic schemas for auth requests/responses (`UserRegisterRequest`, `UserLoginRequest`, `TokenResponse`, `UserResponse`)
- `backend/middleware/auth.py` — FastAPI authentication dependency (`get_current_user`, `require_role`)

### Modified Files
- `backend/app.py` — Mount `auth_router` and register auth middleware
- `backend/requirements.txt` — Add `pyjwt>=2.8.0` and `passlib[bcrypt]>=1.7.4`

## Tasks

### Task 1: Add Auth Dependencies & Security Utilities
- Add `pyjwt` and `passlib[bcrypt]` to backend requirements.
- Create `backend/services/auth.py` providing `hash_password()`, `verify_password()`, `create_access_token()`, `create_refresh_token()`, and `decode_token()`.

### Task 2: Create Auth Pydantic Schemas & Security Dependencies
- Create `backend/schemas/auth.py` defining registration, login, and token models.
- Create `backend/middleware/auth.py` implementing `get_current_user` and `require_role(["admin", "fleet_manager", ...])` dependencies.

### Task 3: Implement Auth Routes & FastAPI Mounting
- Create `backend/routes/auth.py` with endpoints:
  - `POST /api/auth/register`: Create new user record
  - `POST /api/auth/login`: Authenticate and return JWT access + refresh tokens
  - `POST /api/auth/refresh`: Validate refresh token and issue new access token
  - `GET /api/auth/me`: Get current authenticated user details
- Mount `auth_router` in `backend/app.py`.

## Verification Criteria
1. `POST /api/auth/register` creates user with bcrypt hashed password.
2. `POST /api/auth/login` returns valid JWT access and refresh tokens.
3. `GET /api/auth/me` returns current user profile when supplied with `Authorization: Bearer <access_token>` header.
